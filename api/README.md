# API «Созвездия»

API живёт внутри Next.js: обработчики — `src/app/api/**/route.ts`, логика — `src/server/`, контракт — `api/openapi.yaml`.
Фронт ходит в API только через `src/lib/api/client.ts`. Если backend переедет в отдельный сервис, меняется этот файл, экраны остаются.

## Запуск

1. Зависимости: `npm i pg zod` и `npm i -D @types/pg`.
2. Скопируйте `.env.example` в `.env.local` и впишите пароль от PostgreSQL.
3. База — по `db/README.md` (нужна миграция 0004 и свежие сиды).
4. `npm run dev`, откройте http://localhost:3000/login. Код из SMS в режиме разработки — 1234, он же пишется в терминал.

## Как устроено

| Что | Где | Коротко |
|---|---|---|
| Вход | `src/server/auth.ts` | Код из SMS: хеш в `otp_codes`, 5 минут, 5 попыток, не чаще раза в 60 с и 5 раз в час. Сессия — случайный токен в httpOnly cookie, в `sessions` только sha256 |
| Защита кабинета | `src/proxy.ts`, `auth-guard.tsx` | Без cookie — сразу на вход. Протухшая сессия — API отвечает 401, страница уводит на вход |
| CSRF | `src/server/http.ts` | Изменяющие запросы только JSON и только со своего Origin, cookie SameSite=Lax |
| Бриф и версии | `src/server/projects.ts` | После подбора правка брифа создаёт новую версию со своими слотами; после приглашений бриф заморожен |
| Подбор | `src/server/matching.ts` | Специалисты из БД → те же правила, что `src/lib/team-search/matching.ts` → три состава в `team_configurations` |
| Приглашения | `src/server/invitations.ts` | Сервер сам проверяет кандидатов через `candidates_for_slot` и считает цену — фронту не доверяем |
| Ошибки | все обработчики | `{ error: { message, code } }`, message можно показывать человеку |

## Чего пока нет

- **SMS-провайдера.** В продакшне `/api/auth/otp` отвечает 503. Нужен договор с провайдером: стоимость SMS на пилот — вопрос к финансисту.
- **Уведомлений специалистам** о новом приглашении (SMS/email). Сейчас специалист видит приглашение в «Моих проектах».
- **Истечения приглашений по времени.** Поле `expires_at` есть, но перевод в `expired` нужно запускать по расписанию (cron на хостинге).
- **Профиль, портфолио, календарь и публичная страница** пока на моках — это следующий срез.
